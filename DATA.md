# Data

**IBM HR Analytics Employee Attrition (WA_Fn-UseC_-HR-Employee-Attrition)**

- Rows: 1,470 employees, 35 fields
- Source: IBM sample dataset, via the public mirror at TheAlgorithms/Jupyter
- Licence: IBM synthetic sample data, public for analysis
- Attrition rate 16.1 percent. EmployeeCount, Over18 and StandardHours are constant and dropped.

Raw files are **not committed**. Drop the file into `data/` under the name the
script expects, or point a symlink there, then run `python src/main.py`.
